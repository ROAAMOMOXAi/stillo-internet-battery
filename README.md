# STILLO Internet Battery

Research laboratory for testing whether a temporary connectivity opportunity can be represented as a persistent resource that produces measurable utility during a later connectivity state.

## Core loop

OBSERVE → CHARGE → DISCONNECT → PERSIST → RECONNECT → REDEEM → MEASURE → COMPARE

## First experiment

Compare:

1. **Baseline**: temporary connectivity disappears and no persistent resource exists.
2. **STILLO**: a connectivity opportunity creates a persistent resource, the connection disappears, a later connection occurs, and the resource is redeemed for simulated service.

The project distinguishes physical network capacity from its persistent representation.

## Status

Initial laboratory structure. The Internet Battery hypothesis is not yet proven.
